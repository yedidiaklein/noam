# חֶדֶר הַבְּרִיחָה שֶׁל נֹעַם 🔑

> מסע בן חמישה שערים בעקבות אבות האומה ופייטני ישראל — משחק חדר בריחה לכבוד יום הולדתו של נֹעַם.

משחק ווב (PHP + MySQL) בעברית מלאה, בעיצוב קלף־זהב מכובד. חמש קבוצות פותרות חידות מבוססות פיוטים, גימטריה ואקרוסטיכונים, ובסופו של דבר מרכיבות יחד שיר ברכה לנֹעַם שראשי בתיו מצטרפים לאקרוסטיכון **נֹעַם כ״ו**.

---

## 🎲 על המשחק

המשתתפים מתחלקים לחמש קבוצות, וכל קבוצה עוברת שלושה שערים:

| שער | שם | תיאור |
|-----|-----|-------|
| 1 | **זיהוי האב** | כל קבוצה מקבלת בית מהפיוט *"זְכֹר אָב נִמְשַׁךְ אַחֲרֶיךָ כַּמַּיִם"* ומזהה את האב הנרמז (אברהם / יצחק / יעקב / משה / אהרון). |
| 2 | **החידה והקריפטקס** | הפיוט המתאים לאב, עם שלושה רמזי גימטריה שמובילים לקוד תלת־ספרתי לפתיחת קריפטקס וירטואלי. |
| 3 | **החרוז לנֹעַם** | כל קבוצה כותבת חרוז (לימריק) הפותח באות הייחודית שלה. |

### חמש הקבוצות

כל אחת מחמש הקבוצות מקבלת אות ייחודית: **נ · ע · מ · כ · ו**. האותיות מצטרפות לאקרוסטיכון **"נֹעַם כ״ו"**. כאשר כל חמש הקבוצות מסיימות — נחשף השיר המלא.

> 🤫 פתרונות החידות והקודים אינם מופיעים ב־README. הם נמצאים בקובץ `includes/data.php` בלבד, ובלוח הבקרה למנהל (`admin.php`).

## 🛠️ דרישות מערכת

- **PHP** 8.1 ומעלה, עם התוסף `pdo_mysql`
- **MySQL / MariaDB**
- שרת ווב (Apache / nginx) או שרת ה־PHP המובנה לבדיקות

---

## 🚀 התקנה

### 1. העתקת הקבצים
העתיקו את תיקיית הפרויקט לתיקיית ה־web של השרת, לדוגמה `/var/www/html/noam/`.

### 2. יצירת מסד הנתונים
הריצו את קובץ ה־SQL המצורף (יוצר את ה־database, המשתמש והטבלה):

```bash
mysql -u root -p < schema.sql
```

> הטבלה `teams` נוצרת גם **אוטומטית** בטעינת הדף הראשונה. `schema.sql` נחוץ בעיקר ליצירת ה־database והמשתמש.

### 3. עדכון פרטי החיבור
ערכו את `includes/config.php` והתאימו את הפרטים לשרת שלכם:

```php
'db' => [
    'host'     => 'localhost',
    'name'     => 'noam',
    'user'     => 'noam',
    'password' => '********',
],
'admin_password' => '********',   // סיסמת מנהל המשחק
```

### 4. הפעלה
פתחו בדפדפן: `http://<server>/noam/`

לבדיקות מהירות ללא שרת ווב:
```bash
php -S 127.0.0.1:8000
# ואז גלשו אל http://127.0.0.1:8000/
```

## 🎛️ ניהול המשחק

- **לוח בקרה:** `admin.php` — מעקב אחר התקדמות הקבוצות וצפייה בשיר המלא. התחברות עם `admin_password` שב־config.
- **איפוס המשחק:** מתוך לוח הבקרה (כפתור "אִפּוּס הַמִּשְׂחָק"), או מהטרמינל:
  ```sql
  TRUNCATE TABLE teams;
  ```
- **המשך משחק:** קבוצה שסגרה את הדפדפן יכולה לבחור שוב את מספר הקבוצה שלה ולהמשיך מהמקום שבו עצרה.

## 📁 מבנה הפרויקט

```
noam/
├── index.php            # רישום וכניסה
├── stage1.php           # שער 1 — זיהוי האב
├── stage2.php           # שער 2 — חידה וקריפטקס
├── stage3.php           # שער 3 — כתיבת החרוז
├── done.php             # סיום לקבוצה

├── admin.php            # לוח בקרה למנהל

├── assets/
│   └── style.css        # עיצוב משותף לכל הדפים
└── includes/
    ├── config.php       # הגדרות DB וסיסמת מנהל
    ├── db.php           # חיבור ל-DB + יצירת טבלה אוטומטית
    ├── data.php         # תוכן המשחק (פיוטים, חידות, קודים)
    ├── functions.php    # פונקציות עזר
    ├── header.php       # תבנית ראש הדף
    └── footer.php       # תבנית תחתית הדף
```

## 🔒 הערות אבטחה

- אל תשאירו את `db.txt` נגיש מהדפדפן בשרת ציבורי — מחקו אותו או חסמו גישה (למשל ב־nginx: `location ~ \.txt$ { deny all; }`).
- כל פניות ה־DB מבוצעות עם Prepared Statements, הפלט עובר `htmlspecialchars`, והשוואת הסיסמה נעשית עם `hash_equals`.
